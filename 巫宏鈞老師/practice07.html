變數

變數是用來儲存資料的容器，可以用來存放數字、文字、布林值等各種資料的型態。
在Javascript中，可以使用 "var" "let" 或 "const" 關鍵字來宣告變數。

X2 + X + 1 = ?
上面的 "X" 就是變數，可以用來表示一個未知的數值。 "1" 就是一個常數。

自訂函數

函數是用來封裝一段可以重複使用的程式碼區塊，可以用來持行特定的任務或計算。
在Javascript中，可以使用 function() 關鍵字來宣告一個函數。 

            //副程式
            function 函數名稱(參數){
                //函數內的程式碼
                //不需要回傳
            };

有回傳值的函數

有回傳值的函數可以使用 return 關鍵字來回傳一個值，這個值可以被呼叫函數的地方並使用。 

            //有回傳值的函數
            function 函數名稱(參數){
                //函數內的程式碼
                return 回傳值;
            };

判斷式

判斷式是用來根據條件執行不同程式碼區塊的結構，可以用來實現分支的邏輯。

        if (條件){
            //條件為ture執行的程式碼
        } else {
            //條件為false執行的程式碼
        };

         if (條件){
